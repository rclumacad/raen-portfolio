## 📌 Description

A personal portfolio website built as part of a **Web Development Internship Skills Showcase Challenge**. It showcases my projects, technical skills, educational background, and contact information — featuring a dark-themed sidebar layout, smooth tab navigation, per-section color accenting, and a fully working contact form. Built entirely with React and Vite, deployed via GitHub Pages.

---

## ✨ Features

- **7-section sidebar navigation** — Home, About, Projects, Skills, Education, Hobbies, Contact
- **Theme switcher** — Dark, Light, and Black mode (preference saved to `localStorage`)
- **Animated settings button** with dropdown theme panel
- **Per-tab background accent colors** — each section has its own color identity
- **Project cards** with hover README tooltips, per-project logos, and clickable links
- **Working contact form** — validates input and shows a success alert on submit
- **Proficiency bars** in the Skills section
- **Responsive design** — works on both mobile and desktop
- **Smooth transitions** on all interactive elements
