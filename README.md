# Raen Clark Lumacad — Portfolio

Personal portfolio built with React + Vite.

## Tech Stack
React, Vite, CSS Variables, Framer Motion (optional)

## Features
- Sidebar navigation with 7 sections
- Dark / Light / Black mode (saved to localStorage)
- Working contact form with success alert
- Responsive design (mobile + desktop)
- Per-tab background accent colors

## Setup
npm install
npm run dev
